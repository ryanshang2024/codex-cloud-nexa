# NEXA AI Sales Engine · PRD V3.3

Sales Engine 是企业管理端的客户资产与销售分配模块，产品权限、Schema、API、计费及验收以 [统一 V3.3 PRD](prd-v3.3.md) 为规范。

管理旅程为 ICP 配置 → 授权获客研究 → 核验及评分 → 人工审核 → 选择销售负责人及必要资料 → 分配任务 → 跟踪 CRM → 授权范围分析。批量获客、线索分析、配置及导出独立鉴权；销售经理须显式获得研究/配置/导出权限，公司分析须设置授权省份范围。

沿用 HVAC QC/ON、H01–H10（H10 排除）、证据溯源、资质按工作类别核验、Fit/Intent 分离、双语草稿、联系依据与草稿版本人审、DNC 及来源许可导出规则。企业客户池不开放给普通员工；只有当前任务指定资料可经工作端查看。第一阶段发送保持永久关闭，n8n 仅使用独立服务身份和服务端凭据。
