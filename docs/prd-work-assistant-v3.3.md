# NEXA AI Work Assistant · PRD V3.3

Work Assistant 是企业集中管理平台的员工工作端，产品权限、Schema、API、计费及验收以 [统一 V3.3 PRD](prd-v3.3.md) 为规范。

员工只能处理本人当前分配任务及明确授权的信息。首页为我的任务、待跟进、AI 工作助手、工作汇报。任务查询、语音录入、工作摘要及客户跟进草稿按功能授权、字段授权与四级配额执行；禁止自主获客、ICP 配置、批量研究、潜客库搜索/导出与公司级分析。模型及自然语言指令不能改变身份、租户、授权或额度。

普通任务记录、进度更新与 CRM 回写不因付费 AI 限额耗尽被禁用。每项结果回到企业统一任务、商机、项目记录及审计。语音供应商未接入时明确显示关闭状态。生产 PTT 的外部连接需另行配置，目前统一工作记录存入本平台，不声称已与外部 PTT 同步。
