## 0/100 反馈后的迭代状态

- **已修复并后端验证**：画像能力/市场/经营模式证据、采购决策权 Unknown、资质证明语义与施工类别、证据到期后的仪表盘状态；25 个新增回归用例，全套 85 通过。
- **浏览器复验项**：手机 ICP 卡片自动最小宽度问题及画像条件展示；结果见 acceptance-evidence.json。
- **尚未实现完整业务能力**：跨真实数据源的自动研究串联、结构化 AI 语义研究/事实提取、产品知识库与真实品牌参数、生产登录/CI/部署。不能以 adapter 接口或模板选择代替完整业务功能。
- **外部验收前提**：来源许可与实时 API 条款、安全凭据绑定、业务/资质/合规规则及 50 家独立人工标签样本。未完成时相关精准率与转化指标为 null，不自动提高用户评分。
